# Cloud Fronts Group — Web & Digital Infrastructure

Cloud Fronts Group is a Central Texas agency specializing in custom web design, logo branding, site hosting, and digital marketing with no long-term contracts.

## Technical Stack
- **Build System:** Python 3 static site generator (`python3_build/build.py`)
- **Frontend:** HTML5, CSS Variables, Service Worker PWA caching
- **Subdomains:**
  - `otherinterest.cloudfrontsgroup.org` — Research, CLI tooling, and analytics scripts

## Deployment Workflow
All live updates are deployed automatically via GitHub Pages from the `master` branch.
