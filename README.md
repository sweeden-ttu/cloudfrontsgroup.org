# Cloud Fronts Group

Central Texas Technology Access & Innovation Delivery Partnership.

[cloudfrontsgroup.org](https://cloudfrontsgroup.org)

Areas of focus:
- AI/ML Research (AAAI 2026 — Bounded-Agent Security Guardrails)
- HUD Data Analytics & Market Intelligence
- Section 3 Compliance Services
- Community Technology Access Programs
- Foreclosure Market Intelligence (Bell County, TX)

Built with [Jekyll](https://jekyllrb.com) and hosted on GitHub Pages. Pages are thin HTML files
with front matter rendered through `_layouts/default.html`; navigation lives in `_data/nav.yml`;
blog posts are Markdown files in `_posts/` published under `/blog/` with an RSS feed at `/feed.xml`.

Local preview (Ruby 3.4 via rbenv):

```bash
bundle install
bundle exec jekyll serve --livereload   # http://127.0.0.1:4000
```

See `docs/blog-authoring.md` for how to write and share a post.
